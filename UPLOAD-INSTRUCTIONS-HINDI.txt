5. Repository mein assets folder kholo. Add file > Upload files se nayi file whatsapp-preview.jpg upload karo. Path yeh hona chahiye: assets/whatsapp-preview.jpg
6. Commit changes karo aur GitHub Pages deployment finish hone do.
